# Кызыл — Абакан — Красноярск: прототип бронирования (демо)

Кликабельный прототип для согласования концепции с перевозчиком. **Не рабочий сервис:** оплаты нет, брони хранятся только в браузере устройства, все данные тестовые.

## Что внутри
- `index.html` — страница сайта
- `css/style.css` — оформление
- `js/app.js` — логика: поиск, схема салона, продажа по участкам, удержание места 15 минут, имитация оплаты, макеты уведомлений Telegram, страница перевозчика
- `data/route.json` — остановки, цены, водители, расписание. **Все значения тестовые.** Цены и время меняются здесь.

## Экраны
- `#/` — направление, откуда/куда, дата, список рейсов
- `#/trip/...` — схема салона и данные пассажира
- `#/pay/...` — оплата (демо) с таймером
- `#/done/...` — бронь подтверждена и макеты сообщений Telegram
- `#/carrier` — страница перевозчика: места, брони, посадочная ведомость, ручное закрытие места, назначение водителя на рейс и добавление нового водителя
- `#/rules` — правила (тестовый текст)

## Публикация
GitHub Pages: Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.

## Ограничения демо
- Брони видны только на том устройстве и в том браузере, где сделаны.
- «Чужие» брони генерируются автоматически для наглядности.
- Кнопка «Сбросить демо» на странице перевозчика удаляет все брони этого браузера.
